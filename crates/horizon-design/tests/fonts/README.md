# Controlled test fonts

These unmodified fonts are used with system font discovery disabled, so text
tests have consistent family selection and fallback on every machine.

- `InterVariable.ttf`: Inter, from Fedora's `rsms-inter-vf-fonts` package.
  SIL Open Font License 1.1; see `Inter-LICENSE.txt`.
- `LiberationMono-Regular.ttf`: Liberation Mono, from Fedora's
  `liberation-mono-fonts` package. SIL Open Font License 1.1; see
  `Liberation-LICENSE.txt`.

Inter exercises variable weights and UI features. Liberation Mono exercises
monospace selection and Hebrew glyph fallback.
